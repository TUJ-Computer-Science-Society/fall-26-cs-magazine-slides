# fall-26-cs-magazine-slides
Slides for the Official Computer Science Magazine Development Process.


## PDF Compilation
If you want to compile any of these `.tex` files on your own, you'll need to build them thrice for all the references and links to update. Here's a simple command to do so:

```console
for i in {1..3}; do pdflatex <tex_file_name>.tex ; done
```
